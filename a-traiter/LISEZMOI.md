# Cours à traiter

Dépose ici les cours à transformer en paquets Anki (PDF, photos), depuis github.com :
*Add file → Upload files*, puis *Commit changes*.

Ensuite, dans une nouvelle session Claude Code sur ce dépôt, écris par exemple :
- « traite le cours dans a-traiter »
- « traite seulement la partie II du cours dans a-traiter »

Pour prolonger un paquet existant, dépose aussi son export Anki (`.apkg`).

Une fois le cours traité, Claude le range dans le dossier de son chapitre : ce dossier se vide tout seul.
